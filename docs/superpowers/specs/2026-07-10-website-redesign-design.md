## 視覺系統

- 風格：活潑遊戲風——明亮飽和撞色、大圓角卡片、貼紙感徽章、手繪塗鴉線條
- 配色：亮黃（#FFC93C 系）× 珊瑚橘（#FF6B35 系）× 天藍（#2EC4E6 系），
  深色文字底 #2B2B46（遊戲夜空藍）作對比區塊
- 字體：Noto Sans TC（延用），標題用 900 黑體大字級
- 技術：單一 index.html + Tailwind CDN + Lucide icons，不引入 build 工具
